## Overview
This tool automates the process of generating dorks based on a provided wordlist. These generated dorks can then be used to search for websites indexed by Google that match the specified keywords.

## Purpose
* **Research:** Efficiently gather data for research projects.
* **Pentesting:** Facilitate the reconnaissance phase of legal penetration testing.

## Usage
1. **Make the script executable:**
   ```bash
   sudo chmod +x run.sh```
2. **Run the script:**
   ```bash
   ./run.sh```

## Customization
Domains: Add or modify domains in the domains folder.

## Output
The generated dorks will be saved in the r-generatedork folder.

## Additional Notes
* **Legal Use:** This tool is intended for legal and ethical purposes only. Misuse of this tool may have legal consequences.
* **Wordlist Format:** Ensure your wordlist is in a plain text format (e.g., .txt) and each word is on a separate line.
